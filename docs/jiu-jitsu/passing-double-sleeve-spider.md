```markmap
# 过双袖把蜘蛛
- 通用原则
  - 全程低重心蹲姿处理
    - 站着时先蹲下
  - 先让双腿并拢
    - 再向侧面移动
  - 身体前压时
    - 脚步稍微后撤
    - 重心偏前但不要全部扑上去
  - 落位顺序
    - 肩膀先压胸口
    - 手先挡髋
    - 再跪近侧腿
    - 最后跪另一条腿
  - 以下统一向左过腿
    - 向右时镜像处理
- 双脚踩二头
  - 正常蜘蛛
    - 对方踩得不紧
      - 双手同时向后抽袖
      - 身体稍微后带制造张力
      - 双手换抓裤脚
      - 双腿向中间合并
      - 向下、向后压腿
      - 向左绕行
      - 走到约 90 度
      - 左肩压胸口
      - 左手挡髋
      - 先跪左腿
      - 再跪右腿
      - 控髋侧控
    - 对方抓袖特别死
      - 无法换抓裤脚
      - 双手直接扣住膝盖
      - 把双膝折叠并拢
      - 向下压腿
      - 回到侧向绕行路线
    - 对方踩得特别紧
      - 先向前走
      - 把双腿向上翻
      - 等对方主动向下踩
      - 顺着回落力量抽回
      - 合腿下压
      - 回到主链路
  - 长短腿
    - 一条腿伸远
    - 一条腿收近
    - 例：对方左腿短、右腿长
      - 先抓裤脚
      - 从蹲姿起身
      - 向右下压短腿
      - 右脚踩大腿内侧
      - 直腰
      - 把长腿甩向右侧
      - 转 Leg Drag
        - 膝盖必须塞到腋窝后方
        - 右手从腿内侧穿过
        - 抓腰带、腰侧或支撑地面
        - 左手控制后腰或远侧髋
        - 左肩先压胸口
        - 先跪左腿
        - 再跪右腿
        - 控髋侧控
- 双脚踩髋
  - 更容易直接控制膝盖
    - 双手扣住双膝
    - 折叠并拢双腿
  - 身体压在双腿上
    - 双脚稍微后撤
    - 重心偏前
    - 保留转向空间
  - 向左转约 45 度
    - 右前臂向左扫腿
    - 把两条腿一起打下去
  - 双膝跪地
    - 对方双腿夹在两膝之间
  - 上肢控制
    - 左手抄同侧领把
    - 右手抓后腰腰带或衣服
    - 压住髋部
  - 向右换边
    - 防止对方抬腿回防
      - 右脚先勾住近侧腿
    - 左脚 Back Step
    - 绕到另一侧
    - 回到控髋位置
- 一脚踩二头、一脚踩髋
  - 起手
    - 不能站着处理
    - 先蹲下
    - 右手抓裤脚内侧
    - 左手从两腿中路穿入
    - 向回收抓膝盖附近裤把
  - 主链路
    - 抓稳后起身
    - 向左压低膝盖
    - 左脚卡住膝窝内侧
      - 类似 23 式过腿卡腿
    - 右手把腿向下压
    - 塞进左侧腋下
      - 膝盖必须越过腋窝
      - 到达腋窝后方
    - 左手向下穿过
      - 抓腰带
      - 抓髋侧衣料
      - 或支撑地面
      - 挡住对方右侧髋
    - 右肩压胸口
    - 右膝先落地
    - 左腿再收过来
    - 控髋侧控
  - 腿压不下去
    - 无法塞入腋下
    - 不再强求 Leg Drag
    - 自己的腿向外绕开
    - 左手直接抱大腿
    - 右手改为搂颈
      - 不再抄髋
    - 右肩下压
    - 右膝落地
    - 左腿收过来稳定
  - 对方把脚踩到地面
    - 继续按住膝盖
    - 封住髋部
    - 对方失去悬空框架
    - 回到主链路
  - 对方 Sit-up 回防
    - 触发
      - 我蹲下抓把后起身
      - 准备把腿压到地面
      - 对方松开控制我左袖的右手
      - 用另一只手推开我的右臂
      - 顺势 Sit-up 起身
    - 反击
      - 右手反抓对方手腕
      - 把手腕推向我的右侧
      - 左臂从对方右腋下穿过
      - 环住腰背
      - 向左前方约 45 度撞倒
        - 方向与对方后背大致垂直
      - 左腿同时向外划出
      - 滑跪绕开髋部
      - 保持手腕与腰背控制
      - 落到上位整理侧控
```
