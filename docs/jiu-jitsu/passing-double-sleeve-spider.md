  - 保持低重心蹲姿
    - 先合并双腿
      - 再向侧面移动
        - 肩膀先压胸口
          - 手先挡髋
            - 近侧腿先跪

          - 3. 双手换抓裤脚
            - 4. 双腿合并

                - 6. 向左绕到约 90 度

                          - 控髋侧控

          - 3. 等对方主动向下踩

              - 5. 合腿下压
                - 6. 接侧向绕行路线
  - 长短腿
    - 例：对方左腿短、右腿长
      - 1. 先抓裤脚
        - 2. 从蹲姿起身
          - 3. 向右下压短腿
            - 4. 右脚踩大腿内侧
              - 5. 直腰
                - 6. 把长腿甩向右侧

                    - 8. 膝盖塞到腋窝后方
                      - 9. 右手从腿内侧穿过控腰
                        - 10. 左手控制后腰或远侧髋
                          - 11. 左肩压胸口
                            - 12. 先跪左腿
                              - 13. 再跪右腿
                                - 控髋侧控

  - 1. 双手扣住双膝
    - 2. 折叠并拢双腿
      - 3. 身体压在双腿上
        - 脚步稍微后撤

## 总体思路

双袖把蜘蛛的过腿处理按对方脚位分成三类：双脚踩二头、双脚踩髋，以及一脚踩二头一脚踩髋。本文统一以**向左过腿**为例，向右时镜像处理。

连续动作的共同顺序是：保持低重心，先把两条腿合并或固定，再向侧面移动；落位时先压胸、挡髋，最后依次跪腿。不要在对方两条腿仍能分别发力时直接向前冲。

## 1. 双脚踩二头

### 正常拆把

1. 双手同时向后抽袖，身体稍向后带，在双方之间制造张力。
2. 对方蜘蛛脚变轻后，双手换抓同侧裤脚。
3. 将双腿向中间合并，再向下、向后压低。
4. 保持腿被钉住，向左绕到约 90 度。
5. 左肩先压胸口，左手挡住髋部。
6. 先跪左腿，再跪右腿，进入控髋侧控。

!!! warning "落腿顺序"
    必须先让左手获得挡髋空间，再跪近侧腿。如果另一条腿先落地，身体会堵住控髋手的路线。

### 抓袖特别死

无法换抓裤脚时，不继续和袖把角力。双手直接扣住膝盖，把双膝折叠并拢、向下压住，然后接侧向绕行路线。这个反应在双脚踩髋时更常见，但双脚踩二头时也会出现。

### 蜘蛛脚踩得特别紧

先向前走，把对方双腿向其头部方向翻高。等对方为了恢复结构主动向下踩时，顺着回落的力量把腿抽回并压低，不要和最强的蹬力正面对抗。

### 长短腿转 Leg Drag

长短腿是指一条腿伸远、另一条腿收近。以对方左腿短、右腿长为例：

1. 抓住裤脚后起身，向右下方压住短腿。
2. 右脚踩对方大腿内侧，直腰并把长腿甩向右侧。
3. 把对方膝盖送过腋窝，塞到腋窝后方，形成 Leg Drag。
4. 右手从腿内侧穿过控制腰带或腰侧，左手控制后腰或远侧髋。
5. 左肩压胸，先跪左腿，再跪右腿完成控髋。

!!! tip "Leg Drag 的判断"
    只把脚放到腋下还不够；膝盖没有越过腋窝时，对方仍可以转膝回防。

## 2. 双脚踩髋

1. 双手扣住对方膝盖，将双腿折叠并拢。
2. 上半身压住双腿，脚步稍向后撤。重心偏前即可，不要全部扑到前方。
3. 向左转约 45 度，同时用右前臂把并拢的双腿扫向左侧。
4. 双膝跪下，把对方双腿暂时夹在两膝之间。
5. 左手抄同侧领把，右手控制后腰的腰带或衣料。
6. 先用右脚勾住对方近侧腿，阻止其抬腿回防。
7. 左脚完成 Back Step，绕到另一侧建立控髋位置。

## 3. 一脚踩二头、一脚踩髋

### 主链路：Leg Drag

1. 先蹲下，右手抓对方裤脚内侧。
2. 左手从两腿中路穿入，再向回收，抓住膝盖附近的裤把。
3. 抓稳后起身，向左压低膝盖，左脚卡住膝窝内侧。
4. 右手把腿向下压入左腋下，使膝盖越过腋窝。
5. 左手向下穿过，抓腰带、髋侧衣料或支撑地面，挡住对方髋部。
6. 右肩压胸，右膝先落地，再把左腿收过来稳定侧控。

### 腿无法压入腋下

不再强求 Leg Drag。自己的腿向外绕开，左手直接抱住对方大腿，右手改为搂颈；随后右肩下压、右膝落地，再把左腿收过来稳定位置。

### 对方把脚踩到地面

继续按住膝盖并封住髋部。对方的腿失去悬空框架后，接回主链路即可。

## 4. 对方 Sit-up 回防

当我抓把起身、准备压腿时，对方松开右手袖把，用左手推开我的右臂并顺势 Sit-up：

1. 右手反抓对方手腕，把手腕推向我的右侧。
2. 左臂从对方右腋下穿过，环住腰背。
3. 向左前方约 45 度撞倒对方；这个方向大致垂直于其后背。
4. 撞倒的同时，左腿向外划出，以滑跪绕开髋部。
5. 保持手腕和腰背控制，落到上位后整理侧控。
