# De La Riva Guard
- 领臂（同侧领把）
  - 打入
    - 站立 Pull Guard
    - 无需换把位
  - 进攻
    - 左侧
      - 剪刀扫
        - 引申
        - 对方压脚时直接踩地、蹬地发力
        - 看到对方屁股后直接扫倒
    - 右侧
      - 十字固
        - 引申
        - 对方到总指挥位时，向右倒
        - 让对方腿离地
        - 左腿绕出
        - 转 X Guard
    - 前方
      - Sit-up
        - 抱单腿起身
    - 后方
      - 巴投
    - 中路
      - 转 Closed Guard
- 领脚踝（标准同侧领把）
  - 打入
  - 进攻
    - 外侧
      - 前方
        - Sit-up
        - 抱单腿起身
        - Push Sweep
        - 立脚 Push Sweep
      - 右侧
        - 站起扫
          - 大内刈
          - 两手打轮，涮一下
          - 对方手撑地
            - 小内刈
            - 切膝
    - 内侧
      - 拉系
        - 主动总指挥
        - 基础扫
          - 换手起身
        - 基础保持
          - 保持右手臂张力，松开 DLR 钩子
        - 拉挑踝勾回德拉
        - Waiter Guard
        - Y Guard
      - 推系
        - Push Sweep
        - Push Sweep 技术起身
    - 左侧
      - Side Sweep
        - 菠萝
        - Closed Guard
    - 后方
      - 巴投
      - 因对方有手支撑，不容易完成
  - 回防
    - 一般
      - 逆虾行回正
    - 对方进入总指挥位
      - 与进攻相同
    - 对方 Leg Drag 换腿
      - 小腿发力，用腿肚子蹬
      - 绕左腿进来
      - 对方脚踩到锁腿位
      - 拉挑进入 X Guard
    - 对方拆领把
      - 对方未曲膝
        - 抓膝盖处裤子
        - 打拳
        - 勾踢
      - 对方曲膝
        - 逆虾行转 Omoplata
        - 起身抱单腿
        - 抓后衣服领子
        - 打轮
    - 对方拆 De La Riva 钩子做两刷
      - 对方屁股落地
      - 对方屁股没落地
