      - 站姿开腿
        - 左手抓袖把
        - 右手抓领把
        - 立左腿
        - 髋部力量转起右腿
      - 跪姿开腿
        - 右手抓双领把
        - 左手抓裤边、腰带或上衣
        - 左腿打开约 30 度
        - 右腿后撤塞入尾椎骨前
      - 塞腿开防
        - 双手抓领把塞入腋下
        - 重心前移
        - 身体左右晃动并向后撤

        - Knee Slice / Knee Cut Pass
          - 侧控

    - 防守位
      - 肩桥

          - 假设被控的是对方左腿
          - 左手扣肩膀
          - 肘部夹紧对方大臂
        - 后做真动作
          - 右手摸颈
          - 右脚迅速勾住对方脚
          - 向对方被控腿同侧起肩桥
    - 开腿
      - 坐起
      - 身体往后拉
      - 挡脚

        - Knee Slice / Knee Cut Pass
          - 侧控
  - Open Guard（开放式防守）
    - 控制
      - 对方与我有一定距离
        - 蟹行控制距离，保持面对对方
      - 蹲到对方膝上时，对方往一侧分腿
        - 前臂跟随，保持面对对方
      - 对方双手下拉我的双膝
        - 手推脚踝
        - 蟹行后回正，保持面对对方
    - 防守位
      - 扫技
