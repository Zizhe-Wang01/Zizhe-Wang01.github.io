## 双袖把蜘蛛控制

为什么选择双袖把？女生与大级别对手对抗时，力量更强的一方容易依赖上肢和手臂力量；双袖把是相对不吃亏的把位，因此可以纳入下位选择系统。

### 1. 建立双袖把

#### 从 Closed Guard 开始

1. 用领把、三头控制和踩髋直接 Pull Closed Guard。
2. 捕捉对方双手。若对方逃避另一侧手，就拿衣领绞骗出手。
3. 打开 Guard，做两次虾行塞膝，进入双脚踩髋、双袖把控制的状态。

!!! tip "蜘蛛把握法"
    翻开对方袖口，再用大拇指盖住；切勿将大拇指绕到袖口内侧。

#### 对方抓住我的腰带或髋部

踩髋起桥，同时双膝向外打开，完成破把。

### 2. 长短蜘蛛控制

1. 踩上双蜘蛛，用脚的外侧卡住对方肘窝；脚的足弓垫在下侧，踩住对方肱二头肌，形成类似“卡在墙角”的立体脚位。
2. 一侧腿踢成长蜘蛛，另一侧拉紧袖把。骨盆保持朝上，不要让髋侧过去。
3. 短蜘蛛一侧的脚尽量向自己身体回收，只搭住对方肱二头肌，不要向外蹬。

!!! note "距离法则"
    拉力大于踩力时，我的髋离对方更近；踩力大于拉力时，我的髋离对方更远。

### 3. 从双髋双袖转三角绞

1. 一侧脚搭上蜘蛛，另一侧脚踩髋。
2. 踩髋侧拉住袖把，将对方的手臂带到自己身上。注意拉的是手臂，不是手；若拉不住，先向后挪动身体。
3. 将对方手臂带到身体对侧，踩髋起桥。
4. 蜘蛛侧的腿越过对方脖子，用膝窝紧扣脖子，再完成搭扣。
5. 双脚回勾脚趾，双手扶头发力。

### 4. 猎枪十字固

**触发条件：** 对方处于跪姿。我用单侧蜘蛛把和单侧踩髋准备进攻；对方控制踩髋腿并将其牢牢压在地面，但还没来得及完成同侧切膝。

1. 被压住的脚向外打开，踩地做一个幅度较大的逆虾行。
2. 身体横向转约 90 度，让头来到对方肩膀下方。
3. 用 C 字把抓住对方压腿手的手肘，将其固定在胸口。
4. 悠腿摆到对方另一侧脖子上，完成猎枪十字固。

### 5. 从双髋双袖转剪刀扫

先用一侧脚搭蜘蛛，另一侧脚踩髋，再根据对方的底盘选择扫法：

- **对方双脚并拢：** 踩髋脚落到对方同侧脚外侧，同时完成蹬蜘蛛、砍腿和肘撑地转向，扫倒后接骑乘。
- **对方双脚分开、底盘较稳：** 将砍腿改为踢对方膝盖内侧，再完成剪刀扫。

### 6. 剪刀扫转三角绞

对方挺直上半身防守剪刀扫时，支撑脚踩地做逆虾行并直接起髋；蜘蛛腿越过对方脖子，拿到卡脖子的位置后完成搭扣，进入三角绞。
