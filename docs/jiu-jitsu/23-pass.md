## 对方躺姿的外侧过腿起手

共同起手是从对方斜前方约 45 度切入：一只手控制腿，另一只手控制髋，保持低重心，再根据对方的反应选择过腿路线。

| 对方反应 | 优先路线 |
| --- | --- |
| 没有推肩或支撑 | 斗牛过腿 |
| 推肩 | 浮固 |
| 推肩后虾行 | 切膝 |
| 脚踩肩、腿悬空 | Leg Drag、斗牛或换边 Pass |
| 回防腿架在同侧肩膀 | 压迫式转向过腿 |
| 回防腿架在对侧肩膀 | 换手 Back Step；对方伸展时转 Duck Under |
| 脚心踩住对侧肩膀 | 下巴卡髌骨，转 Leg Drag |
| 建立 Lasso | 根据 Lasso 深度选择抽手、Back Step 或反向移动拆把 |

### 1. 斗牛过腿

1. 同侧手控制对方同侧裤腿内侧，并将其压在地面。
2. 滑步走到 45 度，另一只手屈肘控髋。不要伸直手臂，避免被对方踩住。
3. 保持头低于对方膝盖，以低位平板支撑姿态（Camping）匍匐移动到 90 度。
4. 左肩下沉压住对方，再落腿跪下进入侧控；原本控腿的手改为控髋。

### 2. 对方推肩：接浮固

**触发条件：** 在 45 度位置，对方推我，并且我已无法继续下压其腿。

1. 将下压腿改为提腿，把对方侧躺的身体带正。
2. 上步进入浮固。
3. 如果对方在浮固位置继续推，可以寻找手臂十字固。

### 3. 对方推肩后虾行：接切膝

在准备上步进入浮固时，如果对方用未被控制的腿踩地做虾行：

1. 继续将已经控制的一侧腿压在地面。此时对方的髋已经打开。
2. 转髋切膝，确保对方无法建立膝盾。
3. 滑膝寻找对方同侧大臂的位置，用髋部展开对方身体。
4. 保持这个压制姿态，不急于进入侧控。

### 4. 对方脚踩肩或腿悬空：转 Leg Drag

#### 手部控制

1. 在 45 度位置无法拿到对方内侧髋时，用另一只手控制对方踩肩腿的胫骨。
2. 手从内向外 Pummel，将腿收住；左手持续把同侧腿牢牢钉在地面。

#### 脚步与重心

1. 重心压在双手上，像圆规一样向反方向滑步；钉地的左手保持不动。
2. 右手将对方脚带到左侧腋下。
3. 左脚上步到对方被钉地腿的膝窝内侧，右腿稍向后调整，形成稳定的三角结构。
4. 右手将对方膝盖推向左侧腋后，上半身前压，用胸口盖住 Leg Drag 腿的膝盖。

#### 落位

1. 右膝跪地，同时用右肩压住对方胸口。
2. 左手从钉腿改为控制近侧髋，右手控制远侧髋，再将双手放到对方髋部两侧。
3. 双膝打开，进入控髋侧控。

!!! warning "位置提醒"
    此时只是控髋侧控，距离建立 Crossface 的标准侧控还有一段距离。

### 5. 对方脚踩肩或腿悬空：接斗牛或换边 Pass

初步控制与 Leg Drag 相同：

1. 按住对方踩肩脚，从内侧绕手压住对方髌骨。若空间不足，可稍微后倾身体让出空间。
2. 继续向 90 度方向移动。
3. 对方推我时，提腿进入浮固；对方没有推时，直接下沉肩膀完成斗牛侧控。
4. 也可以压住对方髌骨后向反侧移动，同时用另一只手寻找髋部，完成反向斗牛过腿。

### 6. 回防腿架在同侧肩膀：压迫式转向过腿

1. 从 45 度切入，一只手控腿、一只手控髋。对方回防时，大腿膝窝架在我的同侧肩膀上。
2. 同侧手 Underhook 架在肩膀上的腿，并抄到对方腰带。
3. 用架腿侧肩膀向前施压，同时向前调整脚步，形成稳定的三角蹲姿；左脚像 Leg Drag 一样卡住对方的地面腿。
4. 将重心转移到身体右侧，先落右膝，再用抓腰带手的小臂压紧对方髋部，并把重心放在这只小臂上。
5. 左脚向后滑步，做类似原地长步的动作；同时左手拉住同侧腿，迫使对方腿伸长。
6. 完成 Back Step 后，用右肩压住对方胸口。尽量不要让自己的髋落地，以保留更多重心压力。
7. 到达侧面后控制双髋：抓腰带的手控制近侧髋，另一只手盖住远侧髋，进入控髋侧控。

!!! warning "腰带握法"
    抓腰带时使用反手，手心朝上。

### 7. 回防腿架在对侧肩膀：换手 Back Step

1. 沿用上述起手，在 45 度位置向前压迫并跪下左膝。
2. 右手接替左手控制裤把，左手环抱架在肩膀上的腿。
3. 右手提拉对方腿，手肘保持收紧。
4. 左肩将重心压到对方身体外侧，完成 Back Step，用臀部清开对方髋部。
5. 进入南北位，保持胸贴胸。

### 8. 对方伸展身体防守：转 Duck Under

沿用换手 Back Step 的起手。当对方伸展身体防守时，做雨刷动作转到另一侧，完成 Duck Under。

### 9. 对方脚心踩住对侧肩膀：转 Leg Drag

1. 用下巴卡住对方髌骨，右手抱住对方髋部。
2. 左脚上步到 Leg Drag 的起始位置。
3. 左手配合右手，将对方腿收到 Leg Drag 位置。
4. 右肩下压完成过腿。

### 10. 浅 Lasso：抽手回主链路

**触发条件：** 在 45 度位置给手时被对方建立 Lasso，但控制力量适中。

1. 必须在对方斜前方 45 度发起。左手压紧同侧腿，右脚向斜上方、靠近对方臀部的位置迈一小步。
2. 伸直手臂抽手，再 Pummel 到手掌扣住对方大腿的位置。
3. 继续向同侧 90 度绕行。
4. 对方没有支撑时，下沉肩膀完成斗牛；对方用手支撑时，转入浮固。

### 11. 深 Lasso：回正后 Back Step

对方的 Lasso 控制很强时，通常还会主动做逆虾行，把身体回正。这个技术必须在双方正面对齐时使用；如果对方已经回正，我就不需要再额外调整。

1. 左手控制并压住对方地面腿的膝盖。
2. 同侧左腿切过去后，左手移动到对方头顶正上方，使自己的身体处于对方正上方。
3. 被 Lasso 控制的右手，用腋下越过对方膝盖并盖住，使 Lasso 失效。
4. 左手寻找 Crossface，完成 Back Step；右手抽回并藏好，再控制同侧髋进入侧控。

### 12. Lasso 另一侧没有控制：反向拆把

对方搭上 Lasso、但没有控制另一侧时，直接向 Lasso 的对侧移动；调整步伐形成拉弓状态，切掉 Lasso 手。
